# Kakuro (가쿠로)

단일 HTML 파일로 만든 가쿠로(숫자 합 퍼즐) 게임. 수업용·개인용 겸용.

- 바로 하기: https://mathkt.github.io/kakuro/
- 고정 문제 15개(쉬움·보통·어려움 각 5) + 🎲 랜덤 자동 생성 (모두 유일해)
- 메모, 실행취소/다시실행, 틀린 칸 확인(2회), 힌트(3회, 확정 가능한 칸 표시), 타이머
- 합 숫자를 누르면 가능한 숫자 조합 표시(끌 수 있음), 도움말에 조합표
- 크롬북·노트북·폰(세로/가로)·태블릿 대응, 수업용 크게 보기

`index.html` 하나만 열면 됩니다.
